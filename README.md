# Student Mobile Portal

A student portal project for practicing Git and GitHub collaboration.

## Student Profile Component

The `StudentProfile.jsx` component displays a student's basic information:

- Name
- Student ID
- Program

### Sample Student

- Name: Maria Santos
- Student ID: 2026-001
- Program: BS Information Technology


## Example Usage

To use the student profile component in a React application, import it into a component file and render it as shown below:

```jsx
import StudentProfile from "./StudentProfile";

function App() {
  return (
    <main>
      <StudentProfile />
    </main>
  );
}

export default App;
```

This example demonstrates how the StudentProfile component can be imported and displayed in a React application.
